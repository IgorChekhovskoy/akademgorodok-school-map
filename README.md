# Подомовая карта закрепления домов за школами Академгородка

Интерактивная карта показывает, к какой школе закреплены дома в Академгородке, Шлюзе, микрорайоне «Щ» и Ложке / Горках Академпарка.

Публичная версия карты:

https://igorchekhovskoy.github.io/akademgorodok-school-map/

## Что есть на карте

- цветные точки и контуры домов, закрепленных за школами;
- фильтр по одной школе: выбранная школа остается яркой, остальные дома становятся полупрозрачными;
- легенда с цветами школ и переключателями слоев;
- быстрые кнопки перехода к Академгородку, Шлюзу, мкр. «Щ», Ложку и всему охвату;
- слой школ;
- слой дублей / конфликтов, если один адрес формально подходит под несколько правил;
- кнопка скачивания PNG текущего вида карты.

## Охват

Карта включает следующие зоны:

- Академгородок;
- Шлюз;
- мкр. «Щ»;

## Источники данных

Правила закрепления адресов за школами внесены в код карты по постановлению о закреплении территорий за школами на 2026/2027 учебный год.

Ссылка на источник правил указана прямо в интерфейсе карты.

Дороги, здания, адресные объекты и школы загружаются при открытии карты из OpenStreetMap через Overpass API. Поэтому фактическая отрисовка домов зависит от полноты адресных данных в OpenStreetMap.

## Важные ограничения

Карта является справочной визуализацией. Для юридически значимой проверки нужно сверяться с официальным постановлением о закреплении территорий.

Если какого-то дома нет на карте, это не обязательно означает отсутствие закрепления. Возможные причины:

- адрес отсутствует или неполно указан в OpenStreetMap;
- адрес записан в OpenStreetMap в другой форме;
- дом находится вне текущего охвата карты;
- в официальном постановлении адрес задан диапазоном, а в OpenStreetMap номер дома записан с корпусом, литерой или дополнительным обозначением.

Ложок / Горки Академпарка находится вне города Новосибирска и отмечен отдельно.

## Как обновить карту на GitHub Pages

Основной файл сайта — `index.html`.

Чтобы обновить карту:

1. Открой репозиторий `akademgorodok-school-map` на GitHub.
2. Замени файл `index.html` новой версией.
3. При необходимости обнови `README.md`.
4. Нажми `Commit changes`.
5. Подожди несколько минут, пока GitHub Pages обновит сайт.
6. Проверь страницу:

```text
https://igorchekhovskoy.github.io/akademgorodok-school-map/
```

GitHub Pages использует `index.html` как входной файл сайта, если он лежит в корне опубликованной ветки.

## Как запустить локально

Можно просто открыть `index.html` в браузере.

Для более стабильной проверки лучше запустить локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000/
```

## Технически

Карта сделана как один статический HTML-файл без сборки и без серверной части.

Используются:

- Leaflet — интерактивная карта;
- OpenStreetMap / Overpass API — загрузка дорог, зданий, адресов и школ;
- html2canvas — экспорт текущего вида карты в PNG.

## Рекомендации по проверке после обновления

После каждого изменения стоит проверить:

- открытие на компьютере;
- открытие на телефоне по публичной ссылке;
- загрузку адресов;
- фильтр по школе;
- переключатели слоев;
- быстрые кнопки районов;
- скачивание PNG.
